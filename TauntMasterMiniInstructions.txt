#####  Installation  #####

Extract the TauntMasterMini folder into:
   World of Warcraft/_retail_/Interface/AddOns/

Restart WoW or type /reload in-game.
Type /tm to open the options menu.


#####  What It Does  #####

TauntMasterMini is a threat-management addon for tanks.  It displays a
compact frame with one bar per party or raid member.  Each bar shows:

  - Health (status bar)
  - Threat level (bar color: green/yellow/orange/red)
  - Class-colored player name
  - Role icon (Tank / Healer / DPS) on every player bar
  - Cooldown sweeps for your left-click and right-click spells

Below the frame is a raid-marker bar with all 8 markers.  Click a marker to
place it on your current target; click again to remove it.  A marker button
is bright when applied and dim when not.  (Toggle the bar in Options >
Display.)  An optional secure Interrupt button and Target/Focus taunt
buttons can also be enabled.

Click a bar to cast your configured spell:
  Left-click  = primary spell (default: your class taunt)
  Right-click = secondary spell (configurable)

Hostile spells (taunts, damage) are cast on the group member's hostile
target automatically — you never need to manually switch targets.
Friendly spells (blessings, heals) are cast directly on the group member.


#####  Slash Commands  #####

  /tm                    Open options menu
  /TauntMasterMini       Open options menu
  /tm show               Show the frame
  /tm hide               Hide the frame
  /tm toggle             Toggle frame visibility
  /tm lock               Lock frame position
  /tm unlock             Unlock frame position
  /tm spells             Full spell diagnostic (API checks, spellbook dump,
                         flyouts, talents, final filtered list)
  /tm debug              Print each button's unit and macro text
  /tm test [N]           Spawn N randomised dummy bars solo for layout
                         tuning (default 5, max 40); /tm test 0 exits
                         (out of combat only)


#####  Options Menu  #####

Open with /tm or left-click the minimap icon.  Fixed-size tabbed window:
Layout / Display / Spells / Alerts.

  --- Layout ---
  Button Width ......... Horizontal bar size (50-200 px)
  Button Height ........ Vertical bar size (20-60 px)
  Units Per Column ..... Bars per column before wrapping (1-20)
  Max Columns .......... Maximum number of columns (1-8)
  Frame Scale (%) ...... Whole-frame scale (50-150 %)
  Frame Opacity (%) .... Whole-frame opacity (20-100 %)
  Sort ................. Group order / Tanks first / By role / By name
  Test bars ............ Spawn dummy bars solo (also /tm test [N])

  --- Display ---
  Show Minimap Icon .... Toggle the minimap button
  Show Names on Bars ... Toggle class-colored names on bars
  Compact Mode ......... Icon-only threat-coloured squares (no names)
  Flash Bar on Click ... Cast-feedback flash on bar click
  Show Spell Cooldown Indicators ... Dual cooldown icons (left & right spell)
  Show Interrupt Button ............ Secure interrupt button (spell in Spells)
  Show Raid Marker Bar ............. All 8 markers below the frame
  Show Target/Focus Taunt Buttons .. Secure target/focus taunt buttons
  Use Class Colours on Bars ........ Tint bars with the unit's class colour
  Show Self ............ Hide your own button (session-only, resets on reload)
  Hide When Not In Party  Hide the whole frame when solo
  Solo: show Target bar . When ungrouped, show a target threat/health bar
  Hide DPS In Raid ..... In raids, show only tanks and healers
  Lock Frame ........... Lock/unlock position (green border = unlocked)
  Marker Button Size ... Size of raid-marker buttons (12-40 px)
  Interrupt Button Size  Size of interrupt/taunt buttons (12-40 px)

  --- Spells ---
  Left Click Spell ..... Choose from your full spellbook
  Right Click Spell .... Choose from your full spellbook
  Interrupt Spell ...... Interrupt-only spell picker

  --- Alerts ---
  Alert when non-tank pulls ..... Flash + local message (on by default)
  Show "1st Pull by ..." ........ Distinct first-pull notification (on by default)
  Announce pull on-screen ....... Large raid-warning banner (replaces the
                                  old combat-tainted chat announce)
  Play sound on pull alert ...... Sound cue when a pull alert fires


#####  Spell Picker  #####

The spell dropdown scans your entire spellbook:
  - All spellbook tabs (skips guild perks and off-spec)
  - Flyouts (Blessings, Portals, etc.)
  - Active talent tree spells
  - Action bar spells (supplementary)
  - Class default taunt as fallback

Only combat-relevant spells appear: must be harmful, helpful, or have range
(catches dual-purpose spells like Death Coil), non-passive, and not on the
blocklist (Fishing, Cooking, Mining, Skinning, etc.).


#####  Visual Indicators  #####

Threat colors on health bars:
  Green  = No threat
  Yellow = High threat (about to pull aggro)
  Orange = Has aggro but losing it
  Red    = Tanking securely

Cooldown overlays:
  Left half  = left-click spell cooldown (dark clock sweep)
  Right half = right-click spell cooldown

Out-of-range:
  Removed in 7.1.0. Spell range became an opaque "secret value" under
  Midnight (12.0) addon-disarmament and can no longer be read by addons.
  /tm range remains as a diagnostic that demonstrates this.

Icons:
  Class icon (left side)   = the player's class icon
  Role icon (right side)   = Tank / Healer / DPS, from LFG role or spec

Raid marker bar:
  Row of all 8 raid markers below the frame.
  Click a marker = apply it to your current target (button brightens).
  Click again = remove it (button dims).
  Each marker button toggles independently.


#####  Pull Alerts  #####

When a non-tank party member grabs aggro:
  - A red flashing box appears:  >> PULL! <<  [Name]
  - Local chat prints:  TauntMasterMini: [Name] pulled aggro!
  - Optional: a large on-screen raid-warning banner
  - Optional: a sound cue
  (The old party/instance chat announce was removed — the protected
   SendChatMessage call triggered ADDON_ACTION_BLOCKED in combat and is
   disallowed under Midnight addon-disarmament.)

First-pull detection:
  If no one has pulled yet this combat, the first non-tank to grab aggro
  triggers a distinct alert:  >> 1st PULL! <<  [Name]
  with the message:  1st Pull by [Name]!
  Subsequent pulls in the same combat revert to normal alerts.
  First-pull state resets when combat ends.

All three pull settings are enabled by default and can be toggled in /tm.


#####  Supported Tank Classes  #####

  Protection Warrior ........ Taunt
  Protection Paladin ........ Hand of Reckoning
  Blood Death Knight ........ Dark Command
  Guardian Druid ............ Growl
  Brewmaster Monk ........... Provoke
  Vengeance Demon Hunter .... Torment

You can assign ANY spell to left/right click — taunts, blessings, heals,
damage, or defensives.


#####  Troubleshooting  #####

  No bars visible?
    → Join a party or raid.  Solo shows only your own bar.

  Dropdown shows no spells?
    → Type /tm spells for diagnostic.  Reopen picker after a moment.

  Click does nothing?
    → Must be out of combat to rebuild macros.  Type /reload.

  Wrong spell fires after reload?
    → Fixed in 6.3.0.  If it persists, /reload once more.

  Raid marker not applying?
    → Must have a target selected.  Each marker button toggles its
      marker via /targetmarker securely.

  Pull alert not firing?
    → Alert is based on threat healthbar color.  Ensure the non-tank
      actually has aggro (orange or red bar).

  Enable Lua error reporting:
    /console scriptErrors 1

  Reset all settings:
    Exit WoW.  Delete:
      WTF/Account/<YourAccount>/SavedVariables/TauntMasterMini.lua
      WTF/Account/<YourAccount>/<Realm>/<Char>/SavedVariables/TauntMasterMini.lua
    Restart WoW.
